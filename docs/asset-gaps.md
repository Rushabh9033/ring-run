# Ring Run — genuinely missing professional assets

19 Nov 2026.

This is the honest list of artwork that **cannot** be produced procedurally and
still match a premium reference. Every slot below is already wired: the code
references the path, so dropping in a finished file needs no code change.

## 1. The wordmark — the biggest gap

**Slot:** `assets/ui/ring_run_zen/branding/ring_run_logo.png`
**Format:** 1024 × 560 RGBA, transparent background, no drop shadow baked in
(the game draws its own), the plaque centred horizontally with roughly 16%
transparent margin on each side, the lettering on the upper two thirds.

A game title is **drawn**, not generated. The current mark is a jade ellipse
with bevelled LilitaOne lettering — it reads as a competent prototype logo, not
as the launch art of a commercial puzzle game. What is missing that
procedural art cannot fake:

- real bevels with a consistent light direction
- letterforms with proper joins and optical spacing
- a jade surface with depth, not a flat fill
- a gold rim with a highlight that follows the plaque's curve
- foliage that reads as painted bamboo rather than clipped polygons

**What it needs:** an artist's final wordmark, exported as above. The home
screen places it in a centred, aspect-locked box, so any 1024 × 560 image
drops in and looks right.

## 2. The board rings — the second gap

**Slot:** `assets/ui/ring_run_zen/rings/ring_outer_purple.png`
(and `ring_middle_orange.png`, `ring_inner_blue.png`)
**Format:** 1024 × 1024 RGBA each, transparent, same centre, same canvas size.
The radii are already fixed by the code: **0.415 / 0.325 / 0.235** of the
canvas, so the three nest. Keep those radii or the rings will overlap.

The current arcs are drawn well — a dark rim, a lacquered body, a broad sheen
up and to the left, a tight specular, and round caps that continue the
tube's own shading. They are **legible and smooth**, but they are flat vector
arcs. A premium ring wants:

- a soft environment reflection along the tube
- a contact shadow that tightens toward the gap
- micro-variation in the lacquer
- a slight edge wear at the caps

The gameplay rings (not the home preview) are drawn in code by
`gameplay/ring_piece_2d.gd`, so they are **not** affected by this slot. The
slot only governs the home screen's decorative diorama.

## 3. The mascot — the third gap

**Slot:** `art/panda_mascot_celebrating.png`
**Format:** transparent PNG, roughly 512 × 512, the panda centred with a small
margin, no ground shadow.

The panda is reused from the Rotate Rings art, which is the right character
and the right art direction, so this is a **low-priority** gap: it already
looks like the same game. What is missing is a dedicated *celebrating* pose —
the current art is a generic happy panda used for both the idle board
mascot and the modal celebration.

## 4. What is **not** a gap

These are good enough to ship and are generated by
`tools/build_zen_assets.py`:

| Asset | Why it is fine |
|---|---|
| The bamboo garden background | Original art, painterly, already the strongest thing on screen |
| The gold parchment card | Drawn with a stylebox now; a flat fill with a gold rim and a lip reads correctly at any size |
| The button slabs | Styleboxes; the lip and the shadow carry the depth |
| The stone board | A smooth sanded disc; the rings are the subject, the board is the ground |
| The icon set | Twelve icons, one family, one stroke weight |
| The confetti and spark particles | Small, physical, and readable at speed |

## 5. The one thing to **not** do

Do not try to close these gaps with a bigger glow, a heavier drop shadow or a
noise overlay on the procedural art. That reads as "cheap" faster than
"simple" does. If the budget for real artwork does not exist, ship the
procedural art as-is: it is coherent, it is legible, and it looks like one
game.
